# Timeseries_forecasting_sarima-rolling-
This project aimed to develop and evaluate a time-series forecasting framework for predicting healthcare patient volume using historical operational data from 2023–2025. The dataset was first imported and assessed for structure, completeness, data types, descriptive characteristics, and temporal patterns. The date variable was converted into a standardized datetime format, observations were chronologically ordered, and patient volume was defined as the forecasting target. The time series was divided chronologically into training and testing datasets using an 80:20 split to preserve the temporal nature of the data and avoid information leakage.

Several forecasting approaches were evaluated, beginning with Naïve and Seasonal Naïve models as baseline methods. ARIMA was subsequently fitted to capture non-seasonal temporal dependencies, while SARIMA was used to incorporate both non-seasonal and weekly seasonal patterns. Model performance was assessed using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and Mean Absolute Percentage Error (MAPE). The candidate models were compared using test-set performance, followed by residual diagnostics including the Ljung–Box test and stationarity assessment using the Augmented Dickey–Fuller test. Multiple SARIMA configurations were evaluated to identify the best-performing specification. Finally, the selected model rolling_sarima with mape 9.78% was refitted using the complete historical series and used to generate a 30-day forecast. Rolling backtesting and data-validation procedures were additionally implemented to assess model robustness and practical reliability. Moreover, this model is efficient enough to first validate the new data given before forecasting.
